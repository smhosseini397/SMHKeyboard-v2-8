# فایل‌های یادگیری KeyFarsi — همراه پروژه

این پوشه بخشی از خود پروژه است و همراه ZIP/Git مخزن منتقل می‌شود؛ فایل‌های قالب، طرح اعتبارسنجی و سیاست داده اولیه در همین‌جا نگهداری می‌شوند.

## اجزای یادگیری

- `learning_profile_template.json`: قالب نسخه‌دار پشتیبان یادگیری.
- `learning_profile.schema.json`: طرح اعتبارسنجی JSON.
- `seed_corrections.json`: مجموعه شروع عمداً خالی؛ هیچ اصلاح شخصی یا داده ساختگی به کاربر تحمیل نمی‌شود.
- `app/src/main/assets/fa_words.txt`: واژه‌نامه آفلاین همراه APK.
- `app/src/main/assets/semantic/`: مدل فارسی ALBERT، SentencePiece و شناسه توکن‌ها که اسکریپت خروجی مدل تولید می‌کند.
- `app/src/main/java/.../PersianNeuralContextModel.kt`: شبکه کوچک شخصی‌سازی‌شونده که از اصلاحات صریح کاربر یاد می‌گیرد.
- `app/src/main/java/.../LearningProfileBackup.kt`: وارد/خارج کردن همه داده‌های یادگیری شخصی.

## نکته مهم درباره دو نوع مدل

وزن‌های ALBERT مدل عمومی ازپیش‌آموزش‌دیده‌اند و باید به‌صورت asset داخل APK قرار بگیرند. پروفایل شخصی (واژه‌ها، اصلاحات و وزن‌های MLP) در زمان استفاده توسط خود کاربر ساخته می‌شود و داخل حافظه خصوصی برنامه ذخیره می‌شود؛ این داده در فایل پروژه ثابت نیست تا اطلاعات تایپ شخصی کاربر داخل سورس عمومی قرار نگیرد. پشتیبان آن با انتخاب کاربر قابل انتقال است.

## خروجی کاملاً آفلاین

بعد از تولید assetهای ONNX و ساخت APK، تایپ و اصلاح بدون اینترنت انجام می‌شود. ساخت APK از سورس خام به Python و دریافت checkpoint نیاز دارد، مگر اینکه assetهای تولیدشده از قبل در مسیر `app/src/main/assets/semantic/` موجود باشند.
